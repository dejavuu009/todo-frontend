#  ToDo App – Frontend (Next.js + TypeScript)

This is the **frontend** of a fullstack ToDo application built with **Next.js**, **TypeScript**, and **Bootstrap**.  
It connects to a custom backend API and allows users to manage personal tasks with a clean UI.

---

## Features

-  User login & registration
-  User-specific todos (only see your own)
-  Add, edit, delete todos
-  Drag & drop to reorder tasks
-  Task due dates and calendar integration
-  Backend sync (TanStack Query)
-  Fast & responsive UI (Bootstrap + Next.js)

---

##  Tech Stack

- **Next.js** (App Router)
- **TypeScript**
- **TanStack Query (React Query)**
- **Bootstrap 5**
- **CSS Modules**
- **React DnD** (for drag & drop)
- **Vercel** (deployment)
